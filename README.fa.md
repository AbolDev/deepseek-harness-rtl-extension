# DeepSeek Harness RTL

**تنظیم خودکار جهت متن برای خواندن طبیعی‌تر در DeepSeek Harness.**

[English](README.md) · **فارسی**

افزونه‌ای سبک برای Chrome که متن فارسی، عربی و عبری را راست‌به‌چپ و متن انگلیسی و کد را چپ‌به‌راست نمایش می‌دهد. افزونه محلی اجرا می‌شود و برای نصب به ساخت پروژه یا نصب وابستگی نیاز ندارد.

## قابلیت‌ها

- تشخیص خودکار جهت بلوک‌های متن، از جمله پیام‌های جدید و پاسخ‌های در حال تولید.
- تغییر جهت کادر تایپ و بخش‌های قابل‌ویرایش هنگام تایپ.
- حفظ جهت چپ‌به‌راست کدها و ترتیب ستون‌های جدول؛ متن هر سلول می‌تواند جهت مستقل داشته باشد.
- رابط انگلیسی با تم روشن/تیره مطابق سیستم و ابعاد ثابت ۴۴۰ × ۳۶۰.
- کلید روشن/خاموش با تنظیم ذخیره‌شونده و مشترک بین تب‌های پشتیبانی‌شده.
- بدون آمارگیری، فونت خارجی یا درخواست شبکه از طرف افزونه.

این افزونه جهت متن را تغییر می‌دهد، نه چیدمان کلی برنامه را. پروژه مستقل است و افزونهٔ رسمی DeepSeek Harness نیست.

## نصب

1. با گزینهٔ **Code → Download ZIP** مخزن را دانلود و استخراج کنید یا آن را clone کنید.
2. آدرس `chrome://extensions` را در Chrome باز کنید.
3. **Developer mode** را روشن کنید.
4. روی **Load unpacked** کلیک کنید.
5. زیرپوشهٔ **DeepSeek Harness RTL - Chrome Extension** را انتخاب کنید؛ همان پوشهٔ حاوی `manifest.json`، نه ریشهٔ مخزن.
6. تب DeepSeek Harness را یک بار رفرش کنید.

بعد از نصب، تشخیص جهت خودکار است. برای دسترسی آسان به کلید روشن/خاموش، آیکون افزونه را به نوار ابزار سنجاق کنید.

### پشتیبانی مرورگرها

افزونه با Manifest V3 ساخته شده و روی **Google Chrome** تست می‌شود. در هر مرورگر مبتنی بر Chromium هم با همان مراحل **Load unpacked** کار می‌کند:

- Microsoft Edge (`edge://extensions`)، Brave (`brave://extensions`)، Opera، Vivaldi و Arc.

**Firefox نسخهٔ ۱۰۹ به بعد** هم پشتیبانی می‌شود. کد افزونه فقط از APIهایی استفاده می‌کند که Firefox آن‌ها را پیاده‌سازی کرده است؛ بنابراین همان پوشه بدون هیچ تغییری به‌صورت افزونهٔ موقت در Firefox بارگذاری می‌شود:

1. آدرس `about:debugging#/runtime/this-firefox` را باز کنید.
2. روی **Load Temporary Add-on** کلیک کنید.
3. فایل `manifest.json` داخل پوشهٔ **DeepSeek Harness RTL - Chrome Extension** را انتخاب کنید.

Firefox افزونه‌های موقت را هنگام بستن مرورگر حذف می‌کند؛ پس پس از هر بار بازکردن مرورگر باید این مراحل را تکرار کنید. نصب دائمی در Firefox نیازمند انتشار نسخهٔ امضاشده در [addons.mozilla.org](https://addons.mozilla.org) است. برای چنین بسته‌ای، فایل `manifest.firefox.json` (شامل بخش الزامی `browser_specific_settings.gecko`) در مخزن موجود است. Safari پشتیبانی نمی‌شود؛ تبدیل افزونه به Safari نیازمند ابزار `safari-web-extension-converter` اپل در macOS است.

### صفحه‌های پشتیبانی‌شده

- http://127.0.0.1:3080
- http://localhost:3080

عنوان صفحه باید شامل **DeepSeek Harness** باشد. HTTPS، دامنه‌های سفارشی و پورت‌های دیگر به‌صورت پیش‌فرض پشتیبانی نمی‌شوند. الگوی تزریق اسکریپت Chrome میزبان‌های محلی HTTP را پوشش می‌دهد؛ خود اسکریپت قبل از هر تغییری پورت و عنوان صفحه را بررسی می‌کند.

### به‌روزرسانی

فایل‌های افزونه را جایگزین کنید، در `chrome://extensions` روی **Reload** کارت افزونه بزنید و سپس تب‌های Harness را رفرش کنید. پوشهٔ افزونه را در مسیر دائمی نگه دارید.

## روش تشخیص جهت

هر بلوک واجد شرایط برای وجود حروف خط عربی یا عبری بررسی می‌شود. وجود این حروف، جهت بلوک را RTL می‌کند؛ در غیر این صورت جهت LTR است. فارسی نیز با تشخیص خط عربی پوشش داده می‌شود. کد و URL در مواردی که تجزیه‌گر تشخیص می‌دهد از بررسی زبان کنار گذاشته می‌شوند.

افزونه فقط نمایش را تغییر می‌دهد و متن پیام یا مقدار ورودی را بازنویسی نمی‌کند. خاموش‌کردن آن تغییرات جهت اعمال‌شده را حذف می‌کند.

### محدودیت‌ها

- وجود حروف RTL در یک بلوک چندزبانه، کل بلوک را RTL می‌کند؛ حتی اگر بیشتر واژه‌ها انگلیسی باشند.
- مسیرهای خام و ترکیب‌های پیچیدهٔ دوجهته ممکن است همچنان مبهم نمایش داده شوند. بهتر است مسیرها به‌صورت کد درون‌خطی نوشته شوند.
- جهت ورودی به کل کادر قابل‌ویرایش اعمال می‌شود، نه جداگانه به هر خط.
- تغییر ساختار HTML در نسخه‌های آیندهٔ Harness ممکن است به اصلاح انتخابگرها نیاز داشته باشد.
- تم پنجره از سیستم پیروی می‌کند؛ انتخاب دستی تم یا فونت وجود ندارد.

## حریم خصوصی و مجوزها

تنها مجوز API اعلام‌شده **storage** است که وضعیت روشن/خاموش را محلی ذخیره می‌کند. اسکریپت برای تشخیص جهت، متن صفحه را می‌خواند اما محتوای گفت‌وگو را ذخیره یا ارسال نمی‌کند. ابزارهای توسعه ممکن است وابستگی تست یا مرورگر دانلود کنند؛ این ابزارها بخشی از افزونهٔ نصب‌شده نیستند.

## توسعه و تست

افزونه به مرحلهٔ build نیاز ندارد. برای تست‌ها Node.js 22 پیشنهاد می‌شود.

~~~sh
cd tests
npm ci
npm test
~~~

این تست‌ها تشخیص جهت، استریم، تایپ، خاموش‌کردن و بازگردانی استایل، تنظیمات پنجره و بازیابی خطای ذخیره‌سازی را بررسی می‌کنند.

### تست چیدمان مرورگر

~~~sh
cd tests
npx playwright install chromium
npm run test:visual
~~~

برای استفاده از Chrome نصب‌شده به‌جای دانلود Chromium، در PowerShell:

~~~powershell
$env:BROWSER_PATH = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
npm run test:visual
~~~

تست چیدمان، فایل‌های پنجره را با APIهای شبیه‌سازی‌شدهٔ Chrome رندر می‌کند. تم روشن/تیره و ثابت‌ماندن ابعاد در حالت بارگذاری، فعال، متوقف و راهنمای باز بررسی می‌شود. اسکرین‌شات‌ها در `tests/screenshots/` نوشته می‌شوند و وارد Git نمی‌شوند. این تست جای بررسی افزونهٔ نصب‌شده را نمی‌گیرد.

قبل از انتشار، افزونه را به‌صورت unpacked نصب کنید و پیام فارسی/عربی و انگلیسی، استریم، کد، تایپ، کلید روشن/خاموش و بازکردن چندبارهٔ پنجره را در Chrome بررسی کنید.

## رفع مشکل

- **تغییری دیده نمی‌شود:** URL و عنوان صفحه را بررسی کنید، کلید افزونه را روشن کنید و تب را رفرش کنید.
- **ظاهر قدیمی است:** افزونه را Reload کنید، پنجره را ببندید و دوباره باز کنید.
- **خطای تنظیمات:** از **Try again** استفاده کنید؛ اگر ذخیره ناموفق بود کلید را دوباره امتحان کنید.
- **جهت غیرمنتظره:** نمونهٔ کوتاه متن و ساختار مرتبط را بدون اطلاعات خصوصی گفت‌وگو گزارش کنید.

## مشارکت

گزارش باگ قابل‌بازتولید و تغییرات کوچک و مشخص خوش‌آمدند. قبل از ارسال pull request تست‌ها را اجرا کنید. پروفایل مرورگر، snapshot محلی، مسیر شخصی یا خروجی گفت‌وگو را وارد مخزن نکنید.
